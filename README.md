# VibeCast

Погодный оверлей для Windows: снег, дождь, сакура, накопление осадков и интерактивные эффекты. Управление — через системный трей.

## Скачать

[Сборки и установщики](https://github.com/balkunovlevnikolaevich-a11y/VibeCast/releases/latest).

- **VibeCast-Setup.exe** — единый установщик. Сначала доступна Free; после активации кода включается Pro.
- Сборка пока не подписана цифровым сертификатом.

Free включает основные погодные функции, настройки интенсивности и ветра, грозу, гирлянды, взаимодействие со снегом, **трактор и мужчину со снегоуборочной машиной**.

Pro добавляет человека в дождевике и персонажа сакуры. **50 Telegram Stars, бессрочно.** После оплаты бот выдаёт одноразовый код: в Pro откройте настройки → «Активировать персонажей». Код привязывается к одному компьютеру; повторный запрос с того же компьютера разрешён. Подписки нет. Интернет нужен для первой активации, затем подписанная лицензия хранится локально. После переустановки Windows идентификатор компьютера может измениться — обращайтесь в поддержку продавца.

Бот [@VibeCastPay_bot](https://t.me/VibeCastPay_bot) и приём платежей начинают работать только после настройки владельцем. Поддержка: [@VibeCastsupport](https://t.me/VibeCastsupport).

## Обновления

Приложение проверяет стабильные Releases этого репозитория и запускает установщик своей редакции. Проверяются адрес загрузки, размер и SHA-256 из метаданных GitHub. Единая версия обновляется единым установщиком. С предыдущей версии 0.13.4 установите новый установщик вручную. Настройки хранятся отдельно от программы. Тестовые сборки не обновляются автоматически.
