# VibeCast

Погодный оверлей для Windows: снег, дождь, сакура, накопление осадков и интерактивные эффекты. Управление — через системный трей.

## Скачать

[Сборки и установщики](https://github.com/balkunovlevnikolaevich-a11y/VibeCast/releases/latest).

- **VibeCast-Free-Setup.exe** — бесплатная версия, установка для текущего пользователя.
- **VibeCast-Pro-Setup.exe** — дополнительные персонажи с активацией в настройках. Появляется после настройки сервера лицензирования и публикации Pro владельцем.
- Отдельные `.exe` запускаются без установщика. Сборки пока не подписаны цифровым сертификатом.

Free включает основные погодные функции, настройки интенсивности и ветра, грозу, гирлянды, взаимодействие со снегом, **трактор и мужчину со снегоуборочной машиной**. Торнадо — экспериментальная функция; работа со значками требует отдельной проверки на вашей системе.

Pro добавляет человека в дождевике и персонажа сакуры. **50 Telegram Stars, бессрочно.** После оплаты бот выдаёт одноразовый код: в Pro откройте настройки → «Активировать персонажей». Код привязывается к одному компьютеру; повторный запрос с того же компьютера разрешён. Подписки нет. Интернет нужен для первой активации, затем подписанная лицензия хранится локально. После переустановки Windows идентификатор компьютера может измениться — обращайтесь в поддержку продавца.

Бот и приём платежей начинают работать только после настройки владельцем. Адрес бота задаётся при сборке; если он ещё не задан, приложение сообщает об этом.

## Обновления

Приложение проверяет стабильные Releases этого репозитория и запускает установщик своей редакции. Проверяются адрес загрузки, размер и SHA-256 из метаданных GitHub. Free обновляется только на Free, Pro — только на Pro. Настройки хранятся отдельно от программы. Тестовые сборки не обновляются автоматически.

## Сборка

Нужны Windows, Rust stable с MSVC toolchain и Visual Studio Build Tools с компонентом C++.

```powershell
git clone https://github.com/balkunovlevnikolaevich-a11y/VibeCast.git
cd VibeCast
python tools/check_public.py
./build-vibecast.ps1
```

Результат — `release/VibeCast.exe`, `release/VibeCast-Setup.exe`, `release/SHA256SUMS.txt`. Внутренние имена Cargo сохранены для совместимости сборки. Здесь только Free: платных спрайтов, контроллеров персонажей, платёжного сервера и приватных ключей нет.

## Публикация владельцем

Workflow **Free Windows release** собирает приложение и установщик по тегу `vX.Y.Z` или ручному запуску с номером версии. **Free source check** проверяет границу Free/Pro и компиляцию Windows. Pro собирается в закрытом репозитории; сюда публикуются только готовые Pro-бинарники.
